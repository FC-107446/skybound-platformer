# Skybound

A simple 2D platformer game made using JavaScript.

<img width="1057" height="608" alt="image" src="https://github.com/user-attachments/assets/edb02604-d623-489e-a90e-82472a91f4c7" />

## How to play

- Arrow keys to move.
- Space to jump.
- You can only stand on pink platforms and platforms matching the colour of the last fruit you ate.
- Collect the stars to progress through the levels.

## About

Skybound is a 2D platformer I made while learning JavaScript. It uses HTML Canvas for the game and includes different coloured platforms, fruit and stars.

## Built with

HTML, CSS, JavaScript, and HTML Canvas
